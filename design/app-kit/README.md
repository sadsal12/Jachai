# Jachai app UI asset kit

**Icon (B3, "floating notch"):** a black tile with a white **j**. Its dot floats in a round bite outside the tile, like Jachai's bubble over other apps.
**In-app mark (B2, "speech dot"):** the **j** whose dot is a speech bubble.

All SVGs are generated by `../build_kit.py`. Edit that script and re-run `python design/build_kit.py`; don't hand-edit the SVGs.

## Colours (`jachai-tokens.css`)

| Token | Light | Dark | Use |
|---|---|---|---|
| `--primary` | `#111111` | `#F5F5F4` | Tile, j, headlines |
| `--secondary` | `#F2F2F0` | `#1C1C1E` | Cards, header canvas |
| `--bg` | `#FFFFFF` | `#0E0E0F` | Page |
| `--accent` | `#8CA8F9` | `#8CA8F9` | The speech dot and the banner's floating dot only. Set it to `--primary` for strict monochrome |

Every SVG embeds these as CSS variables. Android `VectorDrawable` can't read CSS variables, so swap in the hex values when importing into Android Studio.

## Files

| File | What it is |
|---|---|
| `app-icon.svg` | Store icon, 512 × 512, full bleed, previewed through `<mask id="app-icon-mask">` (rx 115 = 22.5 %) |
| `app-icon-dark.svg` | The same icon for dark previews (the stores still use `app-icon.svg`) |
| `app-icon-adaptive-foreground.svg` + `-background.svg` | Android adaptive icon, 108 dp. The tile and dot sit inside the 66 dp safe circle, so round launcher masks never cut the dot |
| `favicon-16.svg` | Redrawn on a 16 px grid: thicker j, bigger bite. Use it for 16–32 px. `previews/favicon.ico` has 16, 32 and 48 px |
| `mark-j.svg` | B2 in-app mark; follows the system light/dark theme |
| `banner-16x9.svg`, `banner-8x3.svg` | Promo card. Always ink-dark, even in dark mode. `xMinYMid slice` crops from the right, so the left **Text Safe Zone** survives any width |
| `header-bg.svg` | Header background for app screens; follows light/dark. **Text Safe Zone**: x 48–900, y 40–300 |
| `previews/` | PNG renders, including `*-with-text.png` showing the text placement. Sources are in `previews/src/` |

## Rules

- **Text never goes in the SVGs.** It comes from the app, so it can be translated (EN/বাংলা) and scaled by the text-size setting. The commented `<text>` lines in the banners are placement samples only.
- **Minimum icon size:** `app-icon.svg` down to 32 px; below that, use `favicon-16.svg`.
- **Clear space:** around the tile, keep at least the dot's diameter.
- **Don't:**
  - recolour the tile;
  - move the dot inside the tile;
  - add a shadow or gradient to the mark;
  - put the black tile on a black background without its dark version.
- **Trademark:** these are original constructions, but run a trademark and reverse-image search before publishing.
